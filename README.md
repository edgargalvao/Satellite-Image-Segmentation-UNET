This repo presents the codes of supervised classification using 2 m spatial resolution images from the
WPM sensor of the CBERS-4A satellite, employing Deep Learning techniques to map land use and land cover in an
urban area of Rio Claro (SP). The classification model was based on the U-Net architecture, developed in Python. The
training reference and accuracy evaluation (ground truth) were established through supervised classification in ArcGIS
Pro, utilizing the Support Vector Machine (SVM) algorithm and post-classification procedures, including majority
filters and manual pixel editing to more accuracy.
